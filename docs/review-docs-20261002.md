# 1.1.1 文档校对与 review

## 校对依据

本轮开始时，本地提交与 GitHub main 均为 `f1f0091`，线上健康端点返回 `1.1.0`。已有 20 项后端测试和生产依赖检查通过；Jetson 上的门户、检测、计量与 Tunnel 服务正常。

使用指南以用户提供的 Clash Verge 截图和当前服务器中的策略组配置为依据。只读取组名、类型、成员和隐藏标记，没有将节点地址、UUID、订阅链接或用户凭据写入文档。截图不含这些凭据，按原图用于界面说明。

核对了 `Donson - Proxy`、`AI Policy`、`Microsoft Policy`、SG／US 负载均衡组和隐藏的 JP 专用组。通用导入、系统代理及负载均衡行为还参考了 [Clash Verge Rev 快速入门](https://www.clashverge.dev/guide/quickstart.html) 和 [Mihomo 负载均衡文档](https://wiki.metacubex.one/en/config/proxy-groups/load-balance/)。

## 修改内容

| 修改前 | 修改后 | 原因 |
| --- | --- | --- |
| 使用指南笼统地要求“选择一条正常节点” | 按登录、导入、启用订阅、规则模式和系统代理说明操作 | 对应真实操作顺序 |
| 没有解释多个选择组 | 用截图和表格说明主代理组、AI 与 Microsoft 组各自的作用 | 避免误以为修改主代理组会改变全部请求 |
| 节点、组和延迟容易混淆 | 解释负载均衡、隐藏组和毫秒值，说明结果随环境变化 | 不把截图瞬时值当作服务承诺 |
| README 混合功能介绍与历史实现细节 | 整理为项目简介、预览、功能、工作方式、运行、配置、验证和贡献入口 | 让新读者能了解项目并开始运行 |
| 运维说明集中在首页 | 新建部署维护文档，保留备份、退役身份和计量边界 | 提供完整操作入口，同时让 README 更易读 |
| “已复制”调用未注册的勾选图标 | 补齐 Lucide Check 映射 | 修正 review 发现的反馈图标错误 |

语句校对去掉了泛泛的宣传和重复实现说明，改用界面中可找到的操作名称。保留了远程订阅与本地 YAML、月用量与本机计数、源节点状态与客户端实际连接的区别。对“住宅”名称只作为现有线路标识说明，不根据名称保证 IP 属性或网站解锁结果。
