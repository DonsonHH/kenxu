      电脑 / Android / iOS

      使用自己的 Kenxu 账号领取订阅。首次登录先改密，然后按设备完成安装、导入和连接。

      电脑：Clash Verge

      官方下载
      1. 安装适合电脑的版本从官方 Releases 选择稳定版，按操作系统和处理器架构下载安装包。多数 Windows 电脑使用 x64；Apple Silicon Mac 使用 ARM64，Intel Mac 使用 x64。Linux 选择对应发行版和架构，具体文件名以官方说明为准。
      2. 导入自己的订阅到本站「我的订阅」选择 Clash Verge，点击导入。在客户端确认并选中这份配置；未能自动打开时，复制链接，到客户端「订阅」粘贴导入。
      3. 保持规则模式，选择线路在客户端「代理」页保持「规则」，到 Donson - Proxy 选择可用线路或 SG Load Balance。AI 与 Microsoft 请求按各自的专用组选择，详见下方说明。
      4. 开启代理并验证在「首页」或「设置」开启系统代理，再用浏览器访问需要的网站。若某个应用不使用系统代理，按客户端说明配置 TUN。连通性测试可帮助排查，但实际目标网站能否访问仍需亲自测试。
      客户端操作说明

      Android：Clash Meta for Android

      官方下载
      1. 安装客户端从官方 Releases 选择稳定版 APK。常见现代手机一般使用 arm64-v8a；架构不确定时查看设备信息或官方包说明。允许浏览器安装此次下载后，可关闭这项授权。安装受限或下载失败时请联系 Donson 获取协助。
      2. 一键导入，或者从 URL 添加在本站「我的订阅」选择 Clash Meta for Android，点击导入并在应用中保存。手动方式：复制当前链接，打开应用「配置」→「＋」→「从 URL 导入」，名称填 Kenxu、URL 粘贴完整链接；自动更新可设为本站建议的 720 分钟。
      3. 选中配置并启动回到「配置」选中 Kenxu，再到首页点击启动，按 Android 提示允许 VPN 连接。手机会显示 VPN 标识；不要同时运行另一款接管网络的 VPN 应用。
      4. 选择代理并检查访问在应用代理页面保持规则模式，选择已授权的线路或策略组。连接后测试目标网站；断网时先切换线路，再确认订阅已更新。后台经常断开时，可以按需允许该客户端后台运行，但仍可随时主动停止连接。

      iPhone / iPad

      Shadowrocket / Stash

      先使用自己的 Apple 账号从 App Store 获取客户端。可用地区、系统要求和价格以商店页面为准；在 Safari 中打开本站，再选择与你已安装应用对应的导入方式。

      Shadowrocket：导入节点订阅
      1. 选择 Shadowrocket 并导入本站「我的订阅」选择 Shadowrocket，点击导入。若未跳转，复制当前的节点订阅链接，到 Shadowrocket 首页「＋」，把类型改为 Subscribe，粘贴 URL 后保存并更新。
      2. 选择节点并允许 VPN在列表选一条线路，打开连接开关，按系统提示允许添加 VPN 配置，并由你确认设备密码或生物识别。连接后用浏览器访问目标网站。
      3. 使用应用自己的路由设置这个导入提供授权节点，不含 Clash 的 Donson - Proxy、AI 或 Microsoft 策略组与规则。若需要与电脑相同的分组与分流，选择下方 Stash 方式。节点订阅刷新后仍使用同一份账号的计量。
      Shadowrocket App Store 页面
      Stash：导入 iOS YAML
      1. 在本站选择 Stash「我的订阅」选择 Stash 并点击导入；未打开时复制当前 YAML 链接，在 Stash 的配置管理中从 URL 下载，具体入口以应用版本为准。需要安装支持 VLESS Reality / Vision 的较新版本。
      2. 启用配置并连接选中导入的 Kenxu 配置，保持规则分流，选择相应策略组，再开启连接并允许 iOS VPN 配置。此方式保留授权节点、策略组和域名分流，已省略电脑进程规则并改用 Stash 的 DNS 设置；负载均衡使用兼容的策略。

      代理组的用途与选择方式
      页面中的名称用途与选择方式
      Donson - Proxy一般代理流量使用的主选择组。改这里会影响命中此组的流量；有专用策略的站点按对应组处理。
      SG Load Balance新加坡负载均衡组，包含已授权的 SG 节点。客户端按策略分配连接；它不是一台服务器，也不保证合并带宽或总选最低延迟节点。
      US Load Balance美国负载均衡组，包含已授权的 US 节点。使用方式与 SG 组相同，可按目标网站和实际连接情况选择。
      AI Policy命中 AI 规则的请求单独使用这里的选择。截图中选了 US Load Balance；AI 网站有问题时，优先调整这个组，再重新打开连接。
      Microsoft Policy命中 Microsoft 规则的请求使用这里的选择。截图中选了 Azure SG3；调整主代理组不会自动改变这项选择。
      UK@GUSecure2经 SG2 转发到 Glasgow 的线路，本站只支持 TCP。连接异常时可先换其他可用线路。
      Residential@US-LA单独的美国洛杉矶线路，本站通过 Jetson 中转并计量。名称是线路标识；网站能否访问仍以实际结果为准。

      SG／US 的底层组和 JP 专用规则组可能默认隐藏，所以这里不一定逐项显示所有节点。右上角「全局」和「直连」会改变分流方式；日常使用保持「规则」。

      常见问题

      已经导入，但网站打不开

      先确认这份订阅已选中、客户端正在运行、系统代理已开启，并保持「规则」模式。到「代理」测试连接，再选择可用项。AI 或 Microsoft 网站单独失败时，检查对应的专用组；切换后重新打开页面，仍沿用旧连接时可在客户端「连接」中关闭那条连接后重试。

      仍失败时更新订阅再试。联系 Donson 时说明客户端版本、所选组和节点、出错时间或提示；截图时遮住订阅链接和密码。

      为什么主代理组换了，AI 或 Microsoft 仍走原来的节点？

      「规则」模式按请求匹配分流。命中 AI Policy 或 Microsoft Policy 的请求由各自的选择决定，需要进入对应组调整。

      网页显示「正常」，客户端却超时

      「正常」表示 Jetson 最近通过该源节点成功访问了检测网站，默认每 15 分钟检测一次。你的网络、客户端到公开中转入口的连接可能不同；请结合客户端测试和实际访问判断。网页刷新不会反复触发节点检测。

      订阅多久更新一次？

      本站默认建议每 720 分钟，也就是 12 小时更新。管理员调整线路后可以手动更新。已有订阅若保存了其他间隔，在客户端「订阅」卡片的「编辑信息」中修改，界面名称可能随版本不同。

      下载 YAML 和导入订阅有什么区别？

      远程订阅可以更新线路，并读取本站返回的本月用量信息。下载的 YAML 是当时的配置副本，作为本地文件导入后不会自动获得新的线路或订阅用量；平时优先使用自己的订阅链接。

      超过 100 GB 会被停用吗？

      不会。100 GB 是默认的月用量展示参考，实际数值以你的账户卡片为准，不限制流量。每月 1 日按北京时间重算本月用量，累计记录保留。

      网页和 Clash Verge 卡片的用量为什么不同？

      网页默认每分钟更新；Clash Verge 的订阅卡片通常在更新订阅时才读取最新本月用量。客户端左下角的实时速率和本机累计数字也不是这个账号的本月统计。本站只记录经分配入口的上传与下载，不包含直连流量。

      登录提示尝试过多，或者忘了密码

      按页面倒计时等待后再试，确认账号和密码输入正确。忘记密码请联系 Donson 重置；不要连续猜测密码。新初始密码仍需在首次登录时修改。

      订阅链接泄露了怎么办？

      在「我的订阅」重置链接，再把新链接导入客户端。重置会让旧订阅链接失效，但已下载的节点凭据不会自动更换；若别人已经拿到配置，请同时联系管理员处理。
